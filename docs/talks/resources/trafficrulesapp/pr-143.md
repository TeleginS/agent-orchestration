#### Summary

Implements Epic #136: replaces the home "Прогресс за сегодня" (today-scoped) widget with a cumulative, all-time **Progress** widget plus a per-theme "Моя статистика" detail screen.

Closes #137, #138, #139, #140, #141.

- **#137** — `ProgressStore` (`ObservableObject`, `UserDefaults`-backed): `solvedQuestionIds`, `correctSubmissions`, `totalSubmissions`, `totalTestSeconds`, `markSolved(_:)`, `reset()`, plus computed `solvedCount`/`accuracyPercent`/`closedThemesCount(in:)`/`themeProgress(themeId:in:)`. Wired the same way as `TestResultsStore`/`MistakesStore` (constructed in `TrafficRulesApp.init()`, injected via `.environmentObject`, passed into `TestSession`).
- **#138** — `mascotHome` imageset with a temporary vector placeholder (hand-drawn PDF, "Preserve Vector Data"), swappable for real art later with zero code changes.
- **#139** — `TestSession` capture hooks: every `submitAnswer()` increments `totalSubmissions`/`correctSubmissions` and marks the question solved, symmetric with the existing `mistakesStore.markCorrect/markIncorrect`. Every terminal path (`completeTest`, `timeExpired`, `exitTest` — both the practice-abandon early return and the normal path — and `completePractice`) now accumulates its session duration into `progressStore.totalTestSeconds` exactly once. This also fixes the pre-existing "practice time uncounted" gap (`completePractice()` previously persisted no duration at all). `clearHistory()` now also calls `progressStore.reset()`.
- **#140** — `ProgressWidgetView` replaces the old gradient card: hero `Image("mascotHome")`, then Вопросы `solved/2861` + mini bar, Темы `closed/9` + mini bar, Время (adaptive `Xч Yмин`/`Xч`-only-minutes), Верные `accuracy%`. The whole card is a `NavigationLink` pushing `StatisticsDetailView` (works on iOS 15.6 via the existing `NavigationView` + `StackNavigationViewStyle`, same pattern already used for Themes/History/Settings).
- **#141** — `StatisticsDetailView` ("Моя статистика" + subtitle): a read-only list of the 9 test themes, each showing name + `solved/total` (green/gray) + progress bar. No navigation, gating, or tap targets on rows.
- Denominators come exclusively from `QuestionBank` (`totalQuestionsCount` = 2861, new `getQuestionIds(for:)` for per-theme totals) — never `themes.json.teststotalcards`.
- `stats.*` localization keys added to `es`/`en`/`ru.lproj/Localizable.strings`.
